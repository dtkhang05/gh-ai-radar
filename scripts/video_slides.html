Xác định repo AI

Repo nào là "AI"?

  • Khớp tên, topic GitHub (llm, machine-learning, mcp…) hoặc mô tả
  • Topic và mô tả lấy qua GitHub GraphQL, 100 repo mỗi lần gọi
  • 2025: 4.033 repo AI · 2023–2024: 8.313 repo (đã gộp repo đổi tên)
  • Độ phủ 82–89% trên các danh sách chọn tay; kiểm tay 100 repo ngẫu nhiên: 8 sai

Chỉ khớp theo tên thì độ phủ chỉ 20–25%: topic và mô tả là cần thiết.
